- **`src/pagination.py:22` — `important`** — Off-by-one: `end = len(items) - 1` drops the last element. Python slices are exclusive on the right, so the upper bound should be `len(items)`, not `len(items) - 1`. Example: `items = ['a','b','c','d','e']`, `page=1`, `page_size=3` yields `start=3, end=5`, but the clamp sets `end = 4`, so `items[3:4]` returns `['d']` instead of `['d','e']`. Even worse: `items = ['a']`, `page=0`, `page_size=2` gives `end = 0`, so `items[0:0]` returns `[]` instead of `['a']`. When `items` is empty, `end` becomes `-1`, which is semantically wrong (it happens to produce `[]` on an empty list, but `items[0:-1]` on any non-empty list excludes the last element).
