### Correctness

- **`src/netrc_auth.py:17`** — **important** — `os.path.expanduser(f"~/{name}")` always prepends `~/` to the NETRC value. When the user sets `NETRC=/etc/secrets/netrc` (the convention followed by git, curl, wget), `name` is `/etc/secrets/netrc`, so the expression produces `~/etc/secrets/netrc` → `$HOME/etc/secrets/netrc`. The file is never found, credentials are silently lost. The NETRC env var value should be used as-is and only expanded with `os.path.expanduser()` for tilde expansion, not wrapped in `~/{...}`.

The check should be `if netrc_file` to reject empty strings.
