## Summary

The review found two issues in the `xtrim` change, both stemming from one root cause — no validation that a trimming strategy was supplied:

1. **No-strategy call built a malformed command (high)** — `xtrim("events")` emitted `("XTRIM", "events", b"~")` and `xtrim("events", limit=10)` emitted `("XTRIM", "events", b"~", b"LIMIT", 10)`; both are syntax errors on the Redis server.

**Fix applied** (`src/streams.py:34-35`): a single guard raising `ValueError("exactly one of maxlen or minid is required")` when zero or both are set. The existing append logic already handles the valid single-strategy paths correctly, so no other changes were needed.
