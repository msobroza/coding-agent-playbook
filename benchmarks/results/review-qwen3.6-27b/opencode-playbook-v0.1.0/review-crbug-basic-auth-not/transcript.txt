- `src/auth.py:16-17` — The `or` short-circuits: if `given.username != expected.username`, the password `compare_digest` never runs. An attacker can measure the ~200ns difference to determine whether the username is valid, then brute-force only the password. The fix computes both comparisons before branching:

  ```python
  user_ok = hmac.compare_digest(given.username, expected.username)
  pass_ok = hmac.compare_digest(given.password, expected.password)
  return user_ok and pass_ok
  ```

  (Alternatively, concatenate with a delimiter and compare once.)
