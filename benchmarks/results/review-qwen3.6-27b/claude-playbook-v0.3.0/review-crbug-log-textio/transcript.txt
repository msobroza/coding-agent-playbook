### Correctness

- **`src/service.py:37`** — `isinstance(self.log_output, TextIO)` returns `False` for all file objects. `typing.TextIO` is a generic alias; on Python 3.8 it does not match `_io.TextIOWrapper` or `_io.BufferedWriter` at runtime. A string-path log (`log_output="driver.log"`) opens a `TextIOWrapper` — the `isinstance` check fails, and the file is never closed. **important**

- **`src/service.py:37`** — The default `log_output=None` case opens `open(os.devnull, "wb")` producing a `BufferedWriter`. Neither `isinstance(self.log_output, TextIO)` (always False) nor `isinstance(self.log_output, int)` matches. The devnull file descriptor is leaked on every call to `stop()`. **important**
