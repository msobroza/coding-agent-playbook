- **src/feedstorage.py:27** — *Correctness* — `important` — `settings["FEED_STORAGE_FTP_ACTIVE"] or False` reads the raw value via `__getitem__` instead of using `getbool`; when the setting is set on the command line as `-s FEED_STORAGE_FTP_ACTIVE=False`, the value is the string `"False"`, and `"False" or False` evaluates to `"False"` (truthy), so active mode is enabled even though the user explicitly disabled it. Same for `FEED_STORAGE_FTP_ACTIVE=0`, which stores `"0"` — also truthy. Use `settings.getbool("FEED_STORAGE_FTP_ACTIVE", False)` instead.
