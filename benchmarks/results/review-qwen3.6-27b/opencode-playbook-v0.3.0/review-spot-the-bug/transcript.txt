**src/pagination.py:22** — Correctness — `important` — Off-by-one in end clamp: `end = len(items) - 1` drops the final element from the last page. For example, `paginate(["a", "b", "c", "d"], 1, 3)` computes `start=3, end=6`, then clamps `end` to `3`, yielding `items[3:3]` → `[]`. The element `"d"` is silently lost; the caller receives an empty page instead of the single remaining item. The fix is `end = len(items)` (Python's exclusive-end slice already handles the boundary correctly).
